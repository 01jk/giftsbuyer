# giftsbuyer

Telegram-бот для продажи и отправки подарков через магазин. Покупатель выбирает получателя и оплачивает заказ звёздами. Публичная версия поддерживает отправку от магазина.

Установите зависимости из `requirements.txt`, скопируйте `.env.example` в `.env` и задайте собственные параметры Telegram и используемых платёжных сервисов. Для функций Telethon владелец магазина может создать локальную сессию командой `python login_master.py`. Запуск бота — `python bot.py`.
